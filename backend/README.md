# X Beauty Backend

FastAPI backend for the X Beauty demo website.

## Technologies

- FastAPI
- SQLite
- SQLAlchemy
- JWT Authentication
- Python

## Run

Activate virtual environment:

```powershell
.\venv\Scripts\Activate.ps1
```

## Render deployment

Set `CHAKRAVYUH_API_BASE_URL` on the X-Beauty Render service to the root URL of
the deployed Sentinel API. The integration sends telemetry to
`/api/ingest-traffic`; do not include that path in the environment variable.
Without this setting, the backend defaults to `http://127.0.0.1:8000`, which
does not reach a separate Sentinel service from Render.

The integration is fail-open by default. If Sentinel is unreachable or returns
an error, X-Beauty requests continue and the backend logs the ingestion failure.
Verify that the Sentinel service supports `POST /api/ingest-traffic` with the
payload generated by `app/chakravyuh_integration.py`.
